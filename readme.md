Foi uma das minhas primeiras oportunidades de pegar um problema real, que afetava a usabilidade de dados públicos, e transformá-lo em uma solução funcional e organizada.

English:

The Bolsa Família Project — Turning Public Data into Accessible Information

Early in my college career, I faced a very practical challenge: how can I quickly look up data when the file is huge?

  The Federal Government makes data on Bolsa Família beneficiaries available on the Transparency Portal in massive .CSV files—which are large and very difficult to navigate manually. That’s when I decided to create this Java application. (https://portaldatransparencia.gov.br)

The goal was simple: to create a tool that would filter through this mountain of data and deliver what really matters in just a few seconds.

- What the tool does:
  It allows you to easily search for and filter beneficiaries by: Municipality, Beneficiary Name, CPF, Benefit Amount

- What this project taught me:
  More than just manipulating files and formatting values, this project served as my testing ground to get hands-on experience with fundamental Java concepts. I learned how to handle efficient data processing, exception handling, and code organization.

It was one of my first opportunities to take a real-world problem—one that affected the usability of public data—and turn it into a functional and well-organized solution.
